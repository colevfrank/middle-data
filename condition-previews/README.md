# Condition previews (20 × 2)

Generated from live `server/content.js` + `server/screenContent.js`.

Each file is a full page-by-page playthrough for one cell of the factorial design (**20 data types × 2 use cases = 40 conditions**).

Regenerate with:

```bash
node scripts/generate-condition-previews.js
```

Within a cell, scenario order and Block A/B question order are randomized for participants; these previews use a **fixed representative order** (Scenario 1 then 2; questions by ascending id).
